# ScoreSavy - Credit Score Evaluation & Analysis System

## Overview

**ScoreSavy** is a full-stack web application designed to predict a user's credit score using machine learning techniques and provide **personalized suggestions** for improving it. While many credit analysis tools simply show a score, ScoreSavy empowers users with **actionable recommendations**, making it a more intelligent and user-centric financial assistant.

Developed as a collaborative academic project, ScoreSavy integrates data science, modern frontend design, and robust backend architecture.

---

## Features

-  **Credit Score Prediction** using trained ML models
-  **Customized Suggestions** to help users improve their financial health
-  Visual representation of user’s financial metrics
-  Simple and user-friendly form for data input
-  Data stored securely in a MongoDB database

---

## Machine Learning Models

We trained and evaluated two machine learning models for credit score prediction:

- **Linear Regression**  *(Finalized model – better performance and interpretability)*
- **Random Forest Regressor** *(Tested, but less accurate on our dataset)*
